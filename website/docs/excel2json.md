# Excel/CSV to JSON Tool (FeHelper)

## Tool Introduction

FeHelper's Excel/CSV to JSON tool supports converting Excel (.xlsx/.xls) and CSV files, or directly pasted CSV table data, to standard JSON format with one click. The interface is simple and easy to use, suitable for front-end development, data processing, interface debugging and other scenarios.

---

## Main Features

- **Support File Upload**: You can select Excel (.xlsx/.xls) or CSV files, and automatically parse the first worksheet.
- **Support Paste Data**: You can directly paste CSV format table text for conversion.
- **One-Click Conversion**: Click the "Convert to JSON" button to immediately get formatted JSON results.
- **One-Click Copy**: Click the "Copy" button to quickly copy conversion results.
- **Sample Data Filling**: Built-in multiple sets of sample data, click to automatically fill and convert, convenient for beginners to experience.
- **Professional UI Experience**: Left-right split structure, input and output areas of equal height, all operation entrances concentrated at the top, beautiful and efficient interface.

---

## How to Use

1. **Select File**: Click the "Select Excel/CSV File" button to upload local Excel or CSV files.
2. **Paste Data**: Or directly paste table content (CSV format) into the left input box.
3. **Use Examples**: Click "Example: Simple Table/User Information/Score Sheet" to fill in sample data with one click.
4. **Conversion Operation**: Click the "Convert to JSON" button, the right side will immediately display formatted JSON.
5. **Copy Result**: Click the "Copy" button to copy the result to the clipboard.

---

## Notes

- Only supports standard Excel (.xlsx/.xls) and CSV files, with the first row as the header.
- Paste content only supports comma-separated CSV format.
- Does not support multi-headers, merged cells, complex nesting and other advanced table structures.
- For large file content, it is recommended to clean it with a table tool before importing.

## Frequently Asked Questions

**Q: What file formats are supported?**  
A: Supports Excel (.xlsx/.xls) and CSV files, as well as standard CSV text paste.

**Q: Are there any requirements for paste content format?**  
A: Only supports comma-separated, first-row-as-header standard CSV format.

**Q: How to copy the conversion result?**  
A: Click the "Copy" button in the upper right corner to copy the JSON result with one click.

**Q: What if parsing fails?**  
A: Please check if the file/content format is standard, or try cleaning the data with a table tool.
