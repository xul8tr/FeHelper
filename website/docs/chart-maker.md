# Chart Generator Tool

## Tool Introduction

Chart Generator is a professional data visualization tool that supports multiple chart types and rich customization options. This tool helps users quickly create beautiful and professional charts, supports data import, style customization, chart export and other functions, making it a powerful assistant for data analysis and presentation.

## Main Features

### 1. Data Input
- Manual data entry
- Excel/CSV import
- Sample data loading
- Data format conversion
- Data validation

### 2. Chart Types
- Bar charts
- Line charts
- Pie charts
- Scatter plots
- Area charts

### 3. Style Customization
- Color schemes
- Title settings
- Axis labels
- Legend position
- Grid lines

### 4. Export Features
- PNG export
- JPG export
- Image copy
- Data export
- Configuration save
