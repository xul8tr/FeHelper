# Mind Mapping Tool

## Tool Introduction

The Mind Mapping Tool is a professional mind map editor based on KityMinder implementation, supporting creation, editing, saving, and exporting of mind maps. This tool provides an intuitive graphical interface to help users better organize and present their thinking structures, making it a powerful assistant for learning and work.

## Main Features

### 1. Mind Map Editing
- Node creation and editing
- Node relationship management
- Node style settings
- Node icon selection
- Node note addition

### 2. File Management
- Local saving
- File export
- History records
- File list
- Auto-backup

### 3. Editing Functions
- Drag-and-drop operations
- Keyboard shortcut support
- Undo/redo
- Copy/paste
- Node folding

### 4. Export Functions
- JSON format export
- Image export
- Online sharing
- Batch export
- Format conversion

## FAQ

1. **Q: How to save mind maps?**
   A: Click the save button or use keyboard shortcuts to save locally.

2. **Q: Which export formats are supported?**
   A: Supports JSON format export, which can be imported to online version for continued editing.

3. **Q: How to share mind maps?**
   A: You can export JSON files or use online version to share links.

4. **Q: How to backup data?**
   A: It's recommended to regularly export JSON files for backup.
