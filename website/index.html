Detailed Installation Guide

1 Method 1: CRX File Installation (Recommended)

  1. Click the button above to enter Chrome-Stats download page
  2. Click "Download CRX file" to download .crx file
  3. Enter in Chrome address bar: chrome://extensions
  4. Enable "Developer mode" in the top right corner
  5. Drag and drop the downloaded .crx file directly to the extensions page
  6. Click "Add extension" to complete installation

2 Method 2: ZIP File Installation

  1. On Chrome-Stats page click "Download ZIP file"
  2. Extract the downloaded ZIP file to a local folder
  3. Enter in Chrome address bar: chrome://extensions
  4. Enable "Developer mode" in the top right corner
  5. Click "Load unpacked"
  6. Select the extracted folder to complete installation

Important Notes

  • Chrome may prompt "Can't add app from this website", this is normal, choose to continue
  • After installation, it's recommended to disable "Developer mode" to avoid warning prompts
  • Extension functions are identical to store version, supports automatic update checking
  • If you encounter installation issues, you can provide feedback in GitHub Issues
