### 🛠️ Main Functional Modules

#### 📋 JSON Processing Tools
- **JSON Beautification & Validation**: One-click formatting, validation, compression, and decompression of JSON data, supporting large files
- **JSON Diff Comparison**: Supports automatic key-value comparison of two JSON contents, highlighting differences
- **JSON to Excel**: Quickly convert JSON data to Excel format for easy data analysis

#### 🎨 Code Processing Tools
- **Code Beautification**: Supports beautification of JavaScript, CSS, HTML, XML, SQL, and other code formats
- **Code Compression**: Provides HTML, JavaScript, CSS code compression to optimize page load speed
- **Regular Expression**: Built-in regex testing tool with real-time matching and replacement

#### 🔗 Interface Debugging Tools
- **Simple Postman**: Provides API debugging functionality, supporting GET/POST/HEAD request methods
- **WebSocket Tool**: Supports WebSocket connection testing, message sending, and result analysis
- **Interface Mock**: Quickly generate Mock data, supporting multiple data formats

#### 🖼️ Image Processing Tools
- **QR Code Generation & Recognition**: Quickly generate QR codes, supporting text, links, business cards, and other content types
- **Image to Base64**: Supports bidirectional conversion between images and Base64 format
- **Web Screenshot**: Supports visible area screenshots and full-page scrolling screenshots
- **Page Color Picker**: Directly pick color values from any element on a webpage
- **SVG Converter**: Supports bidirectional conversion between SVG and image formats

#### ⚡ Productivity Tools
- **Timestamp Conversion**: Bidirectional conversion between localized time and timestamps, supporting multiple time zones
- **Random Password Generation**: Supports password generation with specified length and character types
- **Sticky Notes**: Supports creating categorized directories, one-click export/import
- **Markdown Conversion**: Supports HTML to Markdown conversion, PDF format download
- **Tampermonkey Tool**: Built-in webpage script injection feature, supporting custom scripts

#### 📋 Detailed Installation Steps

<table>
<tr>
<td width="50%" align="left">

**Method 1: CRX File Installation (Recommended)**

1. Visit [Chrome-Stats](https://chrome-stats.com/d/pkgccpejnmalmdinmhkkfafefagiiiad)
2. Click "Download CRX file" to download
3. Enter in Chrome address bar: `chrome://extensions`
4. Enable "Developer mode" in the top right corner
5. Drag the .crx file to the extensions page
6. Click "Add extension" to complete installation

</td>
<td width="50%" align="left">

**Method 2: ZIP File Installation**

1. Click "Download ZIP file" on Chrome-Stats page
2. Extract ZIP file to local folder
3. Enter in Chrome address bar: `chrome://extensions`
4. Enable "Developer mode" in the top right corner
5. Click "Load unpacked extension"
6. Select the extracted folder to complete installation

</td>
</tr>
</table>
